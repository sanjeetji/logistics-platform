# B2B Order Service

## Overview
Handles enterprise order workflows, approvals, and SLAs.
Acts as an Adapter to the Core Order Service.

## Key Features
- Order Approval Workflows
- SLA Monitoring
- Bulk Order Processing

## Build & Run
```bash
mvn clean package
java -jar target/b2b-order-service-1.0.0-SNAPSHOT.jar
```
