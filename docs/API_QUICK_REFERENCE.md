# API Quick Reference (Logistic Platform)

**Base URL**: `http://localhost:8080`

| Service Area | Endpoint Prefix | Description |
| :--- | :--- | :--- |
| **Auth** | `/api/auth` | Login, Register, Refresh Token |
| **User** | `/api/users` | User profile management |
| **Order** | `/api/orders` | B2C Order placement |
| **Fleet** | `/api/drivers` | Driver management |
| **Dispatch** | `/api/dispatch` | Job assignment |
| **Tracking** | `/api/tracking` | Shipment tracking |
| **Tenant** | `/api/tenant` | B2B Registration |
| **Inventory** | `/api/inventory` | Stock checks |
